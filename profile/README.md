# Omniscape

Omniscape is a white-label short-form content studio for record labels, artist managers and music marketing agencies. Your team picks the photo, the quote or the template, and Omniscape renders vertical content that is ready to post.

## What it makes

- **Pic to Video Renders.** One photo and a line of text become a vertical MP4 with the caption burned in.
- **Slideshow Renders.** A few photos, one line of text and the song underneath, in the TikTok slideshow format.
- **Fan Page memes.** Post-ready memes made from templates, for running fan pages openly.

## For developers

The Renders API turns a photo you already hold plus a line of text into a finished Pic to Video Render. It is asynchronous, so you start a render and poll for it. Slideshow Renders and video memes are not on the API yet. The [examples repo](https://github.com/omniscape-io/renders-api-examples) shows the full flow with nothing but the standard library (and `fetch` in Node).

Questions, or want an API key? Write to info@omniscape.io.
